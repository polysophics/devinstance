# project-tracker

A standalone ServiceNow Fluent starter generated with the Now SDK 4.13.6. Its
application scope is `x_2312405_proj_trk`, separate from the Venue Hub app at
the repository root. It does not define any tables, roles, or sample data yet.

From this directory, use Node.js 20.18 or newer and run:

```sh
npm ci
npm run build
```

The build creates local artifacts only. Do not run `npm run deploy` unless
installation to a specific ServiceNow instance is separately authorized.
